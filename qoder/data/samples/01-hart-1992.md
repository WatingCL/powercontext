# 摘要

非侵入式负荷监测（NILM）只在一处（配电箱）采集电压电流，通过负荷特征把总功率分解到各个电器。
本文提出以稳态有功/无功功率阶跃作为电器特征，用边沿检测把总功率曲线切成"事件"，再由事件序列推断电器状态。

# 方法

核心假设是电器投切会在总功率上留下可分辨的阶跃，两状态电器对应一次向上的阶跃和一次向下的阶跃。
方法分三步：先用滑动窗口检测功率突变，再把突变按幅值与符号聚合为事件，最后用有限状态机把事件映射到电器。
作者强调该方法依赖稳态特征，对功率连续变化的电器（如调光器）不适用。

# 数据集

早期实验在少量住宅上手工标注，没有公开数据集。这一限制使不同方法之间难以比较。

# 结果

演示数值：在单户两周数据上，两状态电器的识别准确率超过 90%，多状态与连续变化电器显著更低。
作者给出的经验是：阶跃阈值需要按户调参，固定阈值跨户迁移会明显掉点。

# 局限

- 稳态阶跃对变频空调、LED 调光等连续变化负荷失效。
- 事件判定依赖阈值，噪声与多电器同时投切会产生大量误报。
- 缺少公开可复现的评测数据。
