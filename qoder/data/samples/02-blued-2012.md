# 摘要

事件式 NILM 研究长期缺少带完整标注的公开数据。BLUED 采集单户住宅约一周的高频电压电流，
并对每一次电器投切给出人工标注的事件时刻与电器标签，用来支撑事件检测与负荷辨识的可复现评测。

# 采集与标注

数据以 12 kHz 采样电压电流，配套提供聚合有功功率序列与事件列表。标注流程是：先由人工观看录屏，
记录每次操作的起止时刻与电器，再与功率曲线对齐。作者说明标注误差主要来自人工对齐的秒级偏差。

# 数据集

单户、约一周、十余种电器；提供事件级标签与电器级功率真值。数据规模不大，但标签密度高，
适合评测事件检测的召回与精确率，不适合训练数据驱动的模型。

# 结果

演示数值：以功率阶跃阈值做基线事件检测，事件级 F1 约 0.75，误报集中在多电器同时投切与待机功率波动。

# 局限

- 只有一户，跨户泛化无法评估。
- 事件标签是人工对齐的，存在秒级偏差，做严格时刻匹配评测时需要容差窗口。
- 采样率高、文件大，处理链条需要自己搭。
