# 摘要

本文按"是否显式检测事件"把 NILM 分成事件式与非事件式两条路线。事件式先检测投切事件再做辨识，
中间结果可解释、便于人工核查；非事件式直接把功率序列映射到各电器功率，端到端但对数据量要求高。

# 方法谱系

- 稳态特征 + 阈值/边沿检测：实现简单，阈值需按户标定。
- 统计检验（GLR、CUSUM）：误报控制更好，小跃变仍是瓶颈。
- 概率模型（HMM 及其因子化形式）：抑制孤立误报，状态空间随电器数增长。
- 数据驱动（CNN、seq2point 等）：多用于非事件式的功率分解，事件式上的工作相对少，且对标注质量敏感。

# 数据集与评测

REDD、UK-DALE、REFIT 面向功率分解，事件标签稀疏；BLUED 提供事件级标注但只有一户。
评测口径不统一：有的算事件级 F1，有的算电器状态准确率，有的算分解误差（如 NDE）。
作者建议同时报告事件级与电器级指标，并公开匹配容差窗口。

# 结论

演示数值：在公开数据上，事件式方法的检测 F1 多在 0.7–0.9，主要误差来源依次是
小幅跃变、多电器同时投切、以及跨户的阈值失效。

# 局限

- 各数据集采样率、标注口径差异大，跨论文数字不可直接比较。
- 端到端方法缺少事件级中间结果，误报原因难以定位。
