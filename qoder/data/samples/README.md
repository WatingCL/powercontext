# 样例语料说明

`data/samples/` 下 5 篇文档是**为演示与验证重写的样本**，不是论文原文：

- 元信息（标题、作者、年份、会议）取自公开发表的文献，便于说明研究脉络；
- 正文是按原论文公开观点重写的中文摘要式文本，**数值均标注"演示数值"**，不可作为引用依据；
- 用途仅限：验证导入、切块、检索、记忆与出稿这条链路能跑通。

真实使用时把 `data/samples` 换成你自己的 PDF 或 Markdown 笔记即可，
`litcontext ingest <你的目录>` 会重新建立索引。论文原文的版权归原作者与出版方所有，
请勿把受版权保护的全文提交到公开仓库。
