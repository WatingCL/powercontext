# SPEC-003 任务持久化规格

> 适用范围：`todoapp.storage.TaskStore`
> 版本：1.0

## SPEC-003-A 存储格式

任务持久化为单个 JSON 文件，顶层结构为对象，
键 `tasks` 的值为任务 dict 数组（字段见 SPEC-001-C）。文件编码为 UTF-8。

## SPEC-003-B 原子写入

保存必须先写入同目录临时文件再原子替换目标文件，
保证任意时刻文件内容完整可解析，不出现半写状态。

## SPEC-003-C 加载行为

存储文件不存在时，`load` 返回空列表且不报错；
文件存在但 `tasks` 为空数组时同样返回空列表。
